# Glyph

**Glyph** — это централизованное хранилище ассетов для всей инфраструктуры. Сервис позволяет управлять глобальными и персональными асетами и категориями через единый веб-интерфейс, обеспечивая консистентность визуальных ресурсов во всех проектах.

---

## Возможности

- **Централизованное хранилище** — все ассеты в одном месте, доступные для любого сервиса в инфраструктуре.
- **Управление асетами и категориями** — создание, редактирование и удаление как глобальных (только администраторам), так и персональных категорий и асетов.
- **Поддержка SVG** — загрузка, хранение и выдача SVG-ассетов. Архитектура готова к расширению на другие форматы.
- **Удобная навигация** — ассеты сгруппированы по категориям с визуальным превью.
- **Аутентификация** — аутентификация по единой, кроссдоменной cookie.

---

## Архитектура

Проект построен по принципу **монорепозитория** с чётким разделением на фронтенд и бэкенд.

### Бэкенд (`backend/`)

| Слой | Описание |
|------|----------|
| `Glyph.Bff` | Backend for Frontend — агрегирует запросы от UI |
| `FileService.Client` | Клиент для взаимодействия с файловым сервисом |
| `Glyph.Assets.Api` | REST API ассетов |
| `Glyph.Assets.Application` | Бизнес-логика и use-cases |
| `Glyph.Assets.Domain` | Доменные модели и правила |
| `Glyph.Assets.Infrastructure` | Доступ к данным, внешние сервисы |
| `Shared.*` | Общие модули: контракты, ядро, логирование, Redis, HTTP, Web |

### Фронтенд (`web/glyph-ui/`)

| Модуль | Назначение |
|--------|------------|
| `app` | Корневой модуль приложения, маршрутизация |
| `core` | Ядро: HTTP-интерцепторы, guards, сервисы аутентификации |
| `features` | Функциональные модули (ассеты, категории, загрузка) |
| `shared` | Переиспользуемые компоненты |
| `styles` | Глобальные SCSS-стили, переменные темы |

- Clean Architecture

**Инфраструктура:**
